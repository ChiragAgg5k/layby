The blueprint

It's just a mise.toml

[tools] and [env] are ordinary mise, and they still work with a plain mise install on your laptop. The [sandbox] table is a namespaced extension that mise ignores.

One file configures your machine and the remote one. There is no Dockerfile per stack, because the toolchain is the declaration.

Where the time goes

The image is the cache

Running mise install at boot costs minutes on every start, and real money on a metered provider. The toolchain is baked into an image at build time instead, so booting is a pull. The expensive install runs once per unique build definition, on whichever builder is cheapest.

Building in CI rather than locally is 4.6× faster than the same cold build on an M-series laptop — and it is free. The tag hashes the whole build definition, not just the toolchain, so a corrected Dockerfile can never silently reuse a stale image.

Two providers, both verified

DigitalOcean earns the default for remote work. Hourly billing makes a per-task sandbox cost a fraction of a cent, tags are first-class so reconciliation never leans on a naming convention, and keys attach per instance. Local Docker stays the fast path — 485 ms and no meter running.

One gap is deliberate: there is no true in-sandbox self-destruct. Doing it properly means writing an API token onto a box running untrusted agent code, and a full-scope token is worse than an occasional orphan. cloud-init powers the instance off at TTL, but a stopped instance still bills for its disk — layby down -expired is what stops the meter.

Status

Where it stands

The Docker and DigitalOcean drivers are both verified end to end — provision, exec, env, exit codes, teardown. Everything on the shortlist is unwritten, and the CLI says so up front rather than failing halfway through a provision.

Exit codes pass through, so an agent can run layby run $ID -- pytest and branch on $?. Progress goes to stderr; stdout stays clean.

The next lever on speed is a snapshot taken after the image pull, which would cut that 2m 45s down to roughly instance-create time alone.
